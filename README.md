This repo contains a my group's final project submission for our information visualization class. The goal of this project was to visualize the effects of social media on player performance, and use that to prove our claim that Jared McCain deserves Rookie of the Year, for using social media trends to his benefit and performing better than most of his teammates' rookie year. The visualizations at the beginning describe Jared McCain's performance with his social media activity, and as you scroll down you start to see the hard statistics further proving that even though his season was cut short, Jared McCain was on track to being ROTY. We set out with this project without any set conclusion and only some speculation, and were pleasent to find moderate correlations and the visualizations pointing in our direction.
https://info-vis-final-project2-git-main-fayzaan-awans-projects.vercel.app/#
Project installation is very simple. The project runs out of a free service known as vercel, and is updated whenever the github repo is updated, since I linked the repo to vercel's deployment. The above link can take you to our deployed project, but this can also be run on a local host web server, through this command python3 -m http.server 9000. Once this command has been run, the user should go enter localhost:9000 in their browser. The project simply requires the data from CSV files included at the root directory.
My group can say that many lessons were learned during the creation of this visualization and project. Through our extensive use of the d3, my group gained heavy knowledge about developing within JavaScript, basic html elements, and basic css styling. We learned how to research and collect data effectively since the readily available datasets weren't very sufficient for our project goals and claims. We also learned how to create advanced visualizations in d3, utilizing advanced interactivity such as the dragging and dropping ability within the bar chart. We learned a lot about the use of a tooltip div, in order to display information in mouseover events. Overall my team learned the extensive uses of D3 and the effort that goes into creating meaningful visualizations.
